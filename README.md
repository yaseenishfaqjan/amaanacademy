# amaanacademy

Static site for [amaanacademy.com](https://amaanacademy.com) — online one-on-one Quran classes (Nazra & Qaida, Hifz, Tajweed, Aalimiyat) with a certified Aalim.

## Deploy

This repo contains the built static site. Deploy by copying all files to the web root (`public_html` / nginx root). Files are at the repository root — `index.html` must sit at the web root.

## Structure

- `index.html`, `about/`, `programs/`, country pages, `pricing/`, `blog/`, `contact/`, `female-quran-teacher/`, city pages, `quran-level-quiz/`, `class-times/`, `ijazah-sanad/`
- `_next/` — compiled JS/CSS assets
- `images/` — image assets
- `sitemap.xml`, `robots.txt`, `llms.txt`, `.htaccess`
